Prospect-zoeker

Vul een postcode in en vind automatisch logistieke bedrijven, distributiecentra, warehouses en crossdocks in de omgeving, via Google Maps. Exporteer de lijst naar Excel voor je opvolging.

Hoe kom ik aan een API-sleutel?
  1. Ga naar console.cloud.google.com en maak een project aan, bijvoorbeeld "MEK prospects".
  2. Koppel een factuuraccount. Google geeft maandelijks gratis tegoed; een zoekactie kost hierboven enkele centen.
  3. Zet onder "API's en services" twee API's aan: Maps JavaScript API en Places API (New).
  4. Maak onder "Inloggegevens" een API-sleutel aan en plak die hierboven. De sleutel wordt alleen op deze computer bewaard.
  5. Tip: beperk de sleutel in Google Cloud tot deze twee API's en stel een dagelijks gebruikslimiet in.
